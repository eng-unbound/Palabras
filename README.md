# ¡Palabras! — тренажёр испанских слов

Тренажёр лексики в стиле Drops: витрина тем, режим «📖 Изучение» с карточками и озвучкой (es-ES) и режим «🎯 Тренировка» с перетаскиванием слова на картинку.

**Сайт:** https://eng-unbound.github.io/Palabras/

## Как устроен репозиторий

| Файл | Что это |
|---|---|
| `index.html` | Готовое приложение (собирается скриптом, руками не править) |
| `words.csv` | Словарь. Сайт загружает его при каждом запуске |
| `img/` | Фото и картинки к словам: `img/<тема>/<слово>.webp` |
| `src/index.src.html` | Исходник приложения |
| `src/art.js` | Нарисованные SVG-иллюстрации (`svg:имя`) и фигуры тела (`fig:`, `head:`) |
| `build.py` | Собирает `index.html` и встраивает `words.csv` как офлайн-словарь |

## Как обновить слова

1. Отредактируйте `words.csv` (можно прямо на GitHub или в Google-таблице с последующим экспортом в CSV).
2. Закоммитьте изменения. Через 1–2 минуты сайт обновится по тому же адресу.
3. Чтобы новые слова работали и без интернета, запустите `python3 build.py` и закоммитьте `index.html`.

### Колонки `words.csv`

`topic_id, topic_es, topic_ru, topic_emoji, added, es, ru, image`

- Темы с более свежей датой `added` (ГГГГ-ММ-ДД) показываются первыми.
- `image` — одно из:
  - эмодзи: `🐔`
  - иллюстрация из `src/art.js`: `svg:judia`
  - фигура с подсвеченной частью тела: `fig:codo`, `head:pelo`
  - цветное пятно: `color:#e53935`
  - эмодзи со значком: `🧑‍🔧+🚗`
  - файл из репозитория: `img/comida/judia.webp`
  - ссылка на картинку: `https://…`

Проверить все картинки можно в приложении: **⚙︎ Словарь → Все картинки**. Слова без картинки показаны бледной заглушкой.

## Google-таблица вместо words.csv

Опубликуйте таблицу (Файл → Поделиться → Опубликовать в интернете → CSV) и вставьте ссылку в **⚙︎ Словарь → Google-таблица** или в `CONFIG.CSV_URL` в `src/index.src.html`.
